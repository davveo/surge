# 功能分期

P0–P2 只做即时通讯本身。音视频、多地、开放平台放到 P3，独立集群，避免和长连接网关抢资源。

## 总览

| 阶段 | 周期 | 同时在线 | 编制 | 基础设施 | 目标 |
|---|---|---|---|---|---|
| P0 可用单聊 | 6–8 周 | 1 万 | 4 人 | 单区 · 2 Gateway · 1 MySQL · 1 Redis | Web 能稳定发文字、看会话、断线可补齐 |
| P1 群聊与媒体 | 8–10 周 | 10 万 | 5–6 人 | 单区 · 4 Gateway · MySQL 主从 · Redis 哨兵 | 群聊、图片文件、已读撤回，接近微信网页版日常使用 |
| P2 百万在线 | 10–14 周 | 100 万 | 6–8 人 | 多 AZ · 16–20 Gateway · TiDB · Redis Cluster · Kafka | 长连接水平扩展，群扇出异步化，会话/消息分片 |
| P3 平台化 | 持续 | 300 万+ | 平台组 | 多 Region · 就近接入 · 独立 RTC 集群 | 搜索、多地接入、音视频、开放能力 |

P0 建议编制：前端 1 + Go 2 + 全栈/测试 1。下一步落地从协议 protobuf、网关心跳、im-core 单聊时间线三条线并行开始。

## P0 可用单聊

**周期**：6–8 周 · **在线**：1 万 · **编制**：4 人

### 范围

| 模块 | 做 | 明确不做 |
|---|---|---|
| 账号 | 邮箱/手机号注册、JWT、刷新令牌、单设备踢下线 | 扫码、第三方登录 |
| 通讯录 | 搜索 ID、直接加好友、会话可发起 | 好友验证、标签 |
| 单聊 | 文本、发送中/失败、重试、时间线倒序 | 语音、表情商店 |
| 会话 | 列表、最后一条、未读红点、置顶本地即可 | 消息免打扰服务端 |
| 同步 | IndexedDB、`last_seq`、刷新可恢复 | 多设备 |
| 部署 | Docker Compose 可演示 | K8s 生产 |

### 交付检查

- [x] 冻结 WS 帧与 protobuf：`auth` / `send` / `ack` / `sync` / `heartbeat`
- [x] 网关：鉴权、心跳、单机连接、uid 路由写入 Redis
- [x] im-core：单聊时间线 + ACK 幂等 + 会话列表未读
- [x] Web：三栏布局、本地队列、断线重连补 seq
- [ ] 验收：杀网关进程后重连，双方消息与未读一致

## P1 群聊与媒体

**周期**：8–10 周 · **在线**：10 万 · **编制**：5–6 人

### 范围

| 模块 | 做 | 明确不做 |
|---|---|---|
| 群聊 | 建群、拉人、踢人、群主、群名头像，上限 200 | 全体禁言高级管理 |
| 媒体 | 图/文件预签名上传、缩略图、进度 | 视频号、朋友圈 |
| 消息 | 2 分钟撤回、单聊已读、正在输入、引用 | 阅后即焚 |
| 账号 | 二维码登录网页版、多 Tab 只保持一条 WSS | 多端消息漫游完整 |
| 通知 | 浏览器 Notification、会话免打扰 | 邮件/短信推送 |
| 体验 | 草稿、@、链接预览基础 | 搜索全站消息 |

### 交付检查

- [x] 群元数据 + 成员表；群消息写扩散 inbox（≤200）
- [x] 单聊已读回执、2 分钟撤回广播、正在输入节流
- [x] Web：建群/拉人/踢人、草稿、浏览器 Notification
- [x] 群成员变更写入 inbox（系统消息）
- [x] STS 直传 OSS（MinIO 预签名 PUT），消息只存 object key 与尺寸/缩略图
- [x] 已登录端生成二维码，网页扫码换票
- [x] 200 人群压测工具：`make g200`（ACK 无丢失；p99 用 `-max-p99-ms` 验收）

## P2 百万在线

**周期**：10–14 周 · **在线**：100 万 · **编制**：6–8 人

### 范围

| 模块 | 做 | 明确不做 |
|---|---|---|
| 规模 | Gateway 集群、Redis 路由、Kafka 扇出 | 跨洲多活 |
| 存储 | cid 分片、热冷分离、历史分页全量 | 无限期冷备策略可后定 |
| 群 | 上限 2000、管理员、公告 | 万人群/频道 |
| 安全 | 限流、敏感词、审计日志、验证码 | 端到端加密 |
| 搜索 | 会话内搜索、全局消息搜索 | 语义搜索 |
| 运维 | SLO 看板、压测 1M 连接、故障演练 | 全自动容量预测 |

### 交付检查

- [ ] 网关 20 节点、连接迁移、路由覆盖与旧连接踢除
- [ ] timeline 同步写、inbox 异步消费、积压告警
- [ ] 消息库按 cid 分片，历史查询走分区键
- [ ] Kafka 异步索引 OpenSearch，搜索与主路径解耦
- [ ] 1M 连接压测 + 抽 30% 网关故障演练

## P3 平台化

**周期**：持续 · **在线**：300 万+ · **编制**：平台组

### 范围

| 模块 | 做 | 明确不做 |
|---|---|---|
| 实时音视频 | 1:1 与小群 WebRTC（独立 SFU） | 和 IM 网关混部 |
| 多地 | 就近接入、会话数据主区写入 | 消息全球强一致多写 |
| 开放 | 机器人、Webhook、开放 API | 小程序生态 |
| 安全 | 可选 E2EE、设备指纹 | 支付 |
| 增长 | 邀请链接、通讯录匹配 | 社交动态 |

### 交付检查

- [ ] 独立 SFU 集群，IM 只传房间信令
- [ ] 就近接入网关，im-core 仍单区主写
- [ ] 开放消息回调与机器人账号
- [ ] 可选会话密钥，服务端只存密文
